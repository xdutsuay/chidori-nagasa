chidori-nagasa runs large language models on your Android device and optionally pairs with a chidori desktop IDE on your local network.

ON-DEVICE

• Offline inference — chat privately with GGUF models; no cloud, no API keys for local chat
• Vision — attach a photo and ask vision-capable models (Gemma, Qwen, Ministral, …)
• Rich chat — markdown replies, reasoning "thinking" sections, saved history
• Tools (optional) — web search, page fetch, and JavaScript; each tool off by default
• Custom models — import your own GGUF files; background downloads with resume
• Flexible storage — SAF picker for multi-GB model files
• Performance — ARM64 optimizations (KleidiAI / OpenMP); Vulkan when available

COMPANION (chidori desktop)

• Pair over LAN via mDNS (_chidori._tcp) or manual host:port
• Monitor coordinator status and Ask / Agent / Plan / Debug runs
• Remote chat through the desktop's attached models
• Opt-in phone-as-inference-node (foreground service)

PRIVACY

No accounts, ads, or analytics. Model catalog downloads use Hugging Face. Optional tools reach the internet only when you enable them. Companion traffic stays on your LAN (cleartext HTTP in v1).
